# 赛鸽亲子鉴定多少钱？

> **核心结论**：赛鸽亲子鉴定没有统一标价，费用受鉴定对象数量、位点覆盖、报告周期等因素影响，具体金额需咨询三狮生物获取官方报价。本文讲清费用构成、流程与注意事项，帮你避免踩坑。

「**赛鸽亲子鉴定多少钱**」是鸽友在需要验证血统时最常问的问题。需要说明的是：亲子鉴定不是标品，费用会因鉴定对象数量、检测位点、出报告周期等因素浮动，**具体金额请咨询三狮生物技术团队获取官方报价**。本文不报具体数字，而是帮你把「钱花在哪、流程怎么走、注意什么」讲清楚。

## 一、亲子鉴定费用由什么决定？

亲子鉴定的费用不是「一口价」，主要受以下因素影响：

| 因素 | 说明 |
|------|------|
| 鉴定对象数量 | 单亲 vs 双亲，参与比对的鸽子数量 |
| 检测位点 | 位点越多、多态性越高，结果越精准 |
| 报告周期 | 加急与否影响价格 |
| 服务内容 | 是否含报告解读与育种建议 |

> 💡 提示：三狮生物采用 58 个独家 SNP 位点，位点更多、分型更稳定。**具体费用以官方报价为准**，建议直接咨询获取方案。血统鉴定服务详情可访问基因检测子站 [genes.sanshibio.com](https://genes.sanshibio.com/)。

## 二、亲子鉴定的完整流程

了解流程，才能明白费用对应的服务内容：

1. **咨询下单**：确认鉴定对象（单亲/双亲）与项目，获取报价。
2. **羽毛采样**：子代与疑似亲本分别拔取 4-6 根胸腹部羽毛，规范采样。
3. **实验室鉴定**：DNA 提取 + 58 位点亲权比对。
4. **出具报告**：含亲权概率的鉴定结论与解读。

完整流程见[赛鸽亲子鉴定](/paternity/)服务页。

## 三、亲子鉴定的价值，值不值这个钱？

鸽友关心的「多少钱」，本质是「值不值」。亲子鉴定的价值在于：

| 场景 | 价值 |
|------|------|
| 血统认证 | 验证名鸽血统真伪，杜绝虚假血统书 |
| 引种交易 | 花大钱引种前验证血缘，降低风险 |
| 育种管理 | 确认配对结果，防止串种 |
| 赛事验证 | 验证参赛鸽血统，保障公平 |

相比「引到一羽假血统种鸽」的损失，鉴定费用是极小的投入。血统越值钱，鉴定越划算。

## 四、做亲子鉴定要注意什么？

1. **样本要规范**：拔取带毛囊的羽毛，避免污染，详见[羽毛采样指南](/blog/feather-sampling-guide/)。
2. **对象要齐全**：尽量提供父母双方 + 子代样本，判定更准。
3. **选正规机构**：看检测位点数量与质控标准，别只比价格。
4. **留好凭证**：报告与[基因身份证](/blog/gene-id-card-guide/)配合，形成完整血统档案。

## 核心要点

1. 亲子鉴定无统一标价——费用随对象数量、位点、周期浮动，需咨询官方报价。
2. 费用构成看四点——对象数量、检测位点、报告周期、服务内容。
3. 流程四步走——咨询、采样、鉴定、出报告。
4. 鉴定是小投入大保障——相比引错种鸽的损失，鉴定费用微乎其微。
5. 别只比价格——位点数量与质控标准才是结果可靠的关键。

### 亲子鉴定和基因身份证要一起做吗？
建议配合。基因身份证为每羽鸽建档，亲子鉴定确认血缘关系，两者结合形成完整血统追溯体系，见[基因身份证](/blog/gene-id-card-guide/)。

### 采样麻烦吗？需要抽血吗？
