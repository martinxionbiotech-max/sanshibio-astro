# 赛鸽新城疫防控全指南

**新城疫（Newcastle Disease）**是赛鸽最严重的病毒性传染病之一，由副黏病毒引起，具有高度传染性和高致死率。了解其症状与防控，是每位鸽友的必修课。

## 病原与传播

新城疫病毒（NDV）主要经以下途径传播：

| 传播途径 | 说明 |
|---------|------|
| 呼吸道 | 病鸽咳嗽、喷嚏产生的气溶胶 |
| 消化道 | 污染的水源、饲料 |
| 接触传播 | 与病鸽直接接触 |
| 媒介传播 | 人员、器具、车辆等机械携带 |

## 临床症状

赛鸽感染新城疫后，常出现以下症状：

- **呼吸道症状**：呼吸急促、张口呼吸、咳嗽
- **消化道症状**：绿色水样腹泻、食欲废绝
- **神经系统症状**：歪头、转圈、翅膀下垂、腿部麻痹
- **产蛋异常**：种鸽产蛋率骤降、软壳蛋

## 为什么早期检测至关重要

新城疫潜伏期短、传播快，一旦出现明显症状往往已造成大面积感染。因此，**早期筛查**是防控的关键。

[三狮生物赛鸽病毒检测](/virus-detection/)采用**荧光定量 PCR 技术**，可在感染早期、尚未出现明显症状时检出病原体核酸，实现「早发现、早隔离」。

## 科学防控策略

1. **疫苗接种**：按免疫程序规范接种
2. **赛前检疫**：参赛、引种前进行病原体筛查
3. **隔离管理**：新引进鸽隔离观察并检测
4. **环境消杀**：定期消毒鸽舍与器具
5. **生物安全**：减少外来人员与车辆进入

## 出现疑似症状怎么办？

1. 立即隔离疑似病鸽
2. 采集口腔拭子送检（[检测流程](/services/)）
3. 咨询兽医，切勿盲目用药
4. 对鸽舍进行彻底消毒

> ⚠️ 提示：新城疫是烈性传染病，发现疑似病例应第一时间隔离并送检，避免扩散。


## 病毒学原理：认识新城疫病毒

新城疫病毒（NDV）属于**副黏病毒科**，基因组为单股负链 RNA。病毒表面有两种关键糖蛋白：

| 蛋白 | 功能 |
|------|------|
| F 蛋白（融合蛋白） | 介导病毒与宿主细胞膜融合，决定病毒毒力 |
| HN 蛋白（血凝素-神经氨酸酶） | 负责吸附宿主细胞，参与释放 |

新城疫病毒毒株毒力差异巨大，从无症状感染到高致死率不等。高毒力毒株可导致赛鸽群在数日内大量发病死亡，因此**早发现、早隔离**是防控的核心。

## 免疫与生物安全实操

1. **规范免疫**：按当地兽医建议的免疫程序接种疫苗，注意疫苗毒株与流行毒株的匹配。
2. **赛前检疫**：参赛、集鸽前进行[病原体筛查](/virus-detection/)，杜绝带毒参赛。
3. **引种隔离**：新引进鸽隔离观察 2-4 周，并做病原体检测。
4. **环境消杀**：定期消毒鸽舍、食槽、饮水器，阻断传播链。
5. **减少应激**：运输、集鸽等应激会诱发潜伏感染，注意抗应激管理。

## 常见问题

### 赛鸽新城疫能治好吗？
新城疫是病毒病，目前无特效药，主要以预防为主（疫苗免疫 + 生物安全）。一旦发病，重点是隔离、防止扩散，配合兽医对症支持治疗。[早期检测](/virus-detection/)是减少损失的关键。

### 新城疫和普通感冒怎么区分？
两者早期症状有相似处（呼吸道症状），但新城疫常伴绿色水样腹泻、神经症状（歪头、转圈），且传播快、死亡率高。建议通过[荧光定量 PCR 检测](/virus-detection/)确诊，切勿凭经验用药。
