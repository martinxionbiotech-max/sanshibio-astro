# Racing Pigeon Breeding & Selection Guide

Racing pigeon breeding is "art + science". Traditionally, fanciers rely on race results, pedigrees and experience; today, **gene testing** adds scientific evidence.

## Pain Points of Traditional Selection

| Pain Point | Description |
|-----------|-------------|
| Long cycle | Multiple generations of racing verification |
| Subjective | Hard to replicate personal experience |
| Pedigree fraud | Fake or messy pedigree records |
| Talent blind spot | Hard to judge squab potential early |

## How Gene Testing Helps

1. **Flight ability** — evaluate endurance, homing, navigation and more via [flight ability testing](/en/flight-ability/).
2. **Bloodline confirmation** — via [paternity testing](/en/paternity/) and [gene ID card](/en/blog/gene-id-card-guide/).
3. **Health screening** — via [virus detection](/en/virus-detection/) to ensure breeder health.

## The Five-Step Method

1. Build gene profiles for core breeders and squabs
2. Assess talent via the 8 flight genes
3. Confirm bloodline via paternity testing
4. Screen health before pairing
5. Plan pairings based on gene data

## FAQ

### Can gene testing replace race results?
No. Genes reveal potential; results reflect overall performance. Combine "genes set direction, training realizes potential, experience fills gaps".
