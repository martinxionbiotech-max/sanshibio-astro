# Pigeon Paternity Test Cost

> **TL;DR**: A pigeon paternity test has no standard price — the fee varies with the number of individuals, locus coverage and report turnaround, so contact the Sanshi Bio team for official pricing. This article explains the cost structure, process and considerations to help you avoid pitfalls.

"How much does a pigeon paternity test cost" is the question fanciers ask most when they need to verify a bloodline. ## What Determines the Cost of a Paternity Test?

The fee is not a "flat price"; it is mainly influenced by:

| Factor | Explanation |
|--------|-------------|
| Number of individuals | Single vs. dual parent, and how many birds are compared |
| Loci tested | More loci with higher polymorphism mean more precise results |
| Report turnaround | Expedited service affects the price |
| Service scope | Whether report interpretation and breeding advice are included |

## The Complete Paternity Testing Process

Understanding the process clarifies what the fee actually pays for:

1. **Consult and order** — confirm the individuals (single/dual parent) and items, and get a quote.
2. **Feather sampling** — pluck 4–6 breast feathers from the offspring and suspected parents separately, following standardized sampling.
3. **Laboratory analysis** — DNA extraction plus 58-locus parentage comparison.
4. **Report issuance** — a conclusion including the parentage probability and interpretation.

See the [pigeon paternity test](/en/paternity/) service page for the full process.

## Is a Paternity Test Worth the Money?

"What does it cost" is really asking "is it worth it." The value of a paternity test lies in:

| Scenario | Value |
|----------|-------|
| Bloodline certification | Verify champion bloodline authenticity; stop forged pedigree papers |
| Breeder import | Verify parentage before spending big on an import, reducing risk |
| Breeding management | Confirm pairing results; prevent accidental cross-breeding |
| Race verification | Verify racing pigeons' bloodlines to protect fairness |

Compared with the loss of "importing a fake-bloodline breeder," the test fee is a tiny investment. The more valuable the bloodline, the more worthwhile the test.

## What to Watch Out For

1. **Standardize the sample**: pluck feathers with follicles and avoid contamination — see the [feather sampling guide](/en/blog/feather-sampling-guide/).
2. **Provide complete individuals**: ideally provide both parents plus the offspring for a more reliable result.
3. **Choose a reputable provider**: check the number of loci and quality-control standards — don't compare prices alone.
4. **Keep records**: pair the report with a [gene ID card](/en/blog/gene-id-card-guide/) to build a complete bloodline archive.

## FAQ

### How much does a pigeon paternity test cost?
The fee is not fixed — it varies with the number of individuals, loci and report turnaround, so contact the Sanshi Bio team for official pricing.

### Do I need samples from both parents?
Ideally yes, for a more reliable result; single-parent testing is also possible. See [paternity testing](/en/paternity/).

### How accurate is a paternity test?
Based on SNP-locus parentage comparison, the accuracy of excluding non-parents exceeds 99.9% — a reliable method for kinship determination.

### Does expedited reporting cost extra?
Report turnaround affects the fee, and expedited service usually requires separate confirmation. Final pricing follows the official quote — [contact us](/en/contact/) to confirm.

### Should I do a paternity test and a gene ID card together?
It is recommended. The gene ID card files each pigeon, and the paternity test confirms relationships; together they form a complete bloodline traceability system — see the [gene ID card](/en/blog/gene-id-card-guide/).

### Is sampling a hassle? Do I need to draw blood?
No blood is needed. Plucking 4–6 breast feathers yields enough DNA, and squabs can be tested too. See the [feather sampling guide](/en/blog/feather-sampling-guide/) for the standardized method.
