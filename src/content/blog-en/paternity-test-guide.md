# Racing Pigeon Paternity Test Guide

> **TL;DR**: Pigeon paternity testing uses DNA parentage analysis to confirm bloodlines scientifically — the core tool for pedigree certification and breeding management.

In pigeon trade and breeding, "bloodline" is the core of value. Traditional leg rings and pedigree papers cannot fully prevent fraud; **DNA paternity testing** makes bloodline verifiable.

## The Science

Paternity testing is based on **Mendelian inheritance** — offspring inherit half their genes from each parent. Testing compares alleles at multiple highly polymorphic **SNP loci**:

1. **Exclusion**: if a suspected parent lacks an allele the offspring must inherit, parentage is excluded.
2. **Confirmation**: if all alleles match, a **Paternity Index (PI)** and **Combined Probability** are computed to confirm.

[Sanshi Bio](/en/about/) uses **58 exclusive SNP loci** for accuracy.

## FAQ

### Do I need both parents for testing?
Both parents give a higher confirmation probability; single-parent testing is also possible. See [paternity testing](/en/paternity/).

### How accurate is paternity testing?
SNP-based parentage analysis can exclude non-parents with over 99.9% accuracy.

### Do I need both parents' samples?
Ideally provide suspected parents and offspring — more samples mean more accurate determination.

## Key Takeaways

1. Parentage via SNP comparison — determines parent-offspring relationships.
2. Three applications — pedigree certification, breeding management, race eligibility.
3. High accuracy — molecular parentage determination is highly reliable.
4. Feather testing — no blood needed, squabs can be tested.
5. Complements gene ID cards — profile + parentage for full bloodline management.
