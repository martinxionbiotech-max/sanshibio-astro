# SanshiBio Numeric Claims Audit

Date: 2026-11-24  
Scope: Chinese and English articles and service pages.

## Patterns checked

```text
99.99 / 99.9 / 99%
58 SNP / 58个SNP
Ct
8 genes / 8 项基因
10 pathogens / 10 种病原
24 hours / 24小时
```

## Result

No page containing one of these patterns was found without either a `Sources`/`References` section or at least two external links. That is a **presence** check, not proof that the source supports the exact claim.

## Claims that need a primary-source check

| Claim type | Why it matters | Priority |
|---|---|---|
| 99.99% paternity probability | depends on CPI, marker panel and laboratory method | P1 |
| 99.9% sexing accuracy | must identify the assay, sample and validation | P1 |
| Ct cut-offs | assay- and laboratory-specific | P1 |
| 58 SNP loci | panel-specific; should state that panels are not interchangeable | P1 |
| 8 flight genes | association, not a deterministic score | P1 |
| 10 pathogens | must match the current panel list | P1 |
| 24-hour / turnaround claims | operational claim; must match current service capacity | P2 |

## Editorial rule

For every numeric claim:

1. state what the number measures;
2. name the method/panel/sample it applies to;
3. link to a primary source or the laboratory's method note;
4. state the boundary (not a guarantee, not directly comparable across panels).

Wikipedia may be used for orientation, but not as the only support for a commercial diagnostic claim.
